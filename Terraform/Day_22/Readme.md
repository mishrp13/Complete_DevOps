“In this project, I implemented a 2-tier AWS architecture using modular Terraform. I created separate modules for VPC, security groups, EC2, RDS, and Secrets Manager. The root module acts as the orchestrator and passes outputs from one module as inputs to another. EC2 runs the Flask application in a public subnet, while MySQL RDS is deployed in private subnets. I secured the database by allowing port 3306 only from the EC2 security group. For credentials, I generated the database password using Terraform's random provider and stored it in AWS Secrets Manager instead of hardcoding it. I also used EC2 user-data to automatically install and configure the Flask application. Finally, I deployed everything using terraform init, plan, and apply and verified that the application could communicate with the private RDS database.”
